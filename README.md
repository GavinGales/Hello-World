# Hello-World: My First GitHub Repository

## Description
This is my first practice repository for **BAIS:3050 Professional Preparation**. I created it to learn how GitHub works and to practice documenting my work with *Markdown*. It includes sample files from my professional portfolio.

## Tools Used
- GitHub (repository hosting and README editing)
- Markdown (formatting)
- Python 3 (Jupyter Notebook)
- PDF (résumé)

## Files Used
1. `Gavin-Gales_Resume.pdf`: my current résumé, covering my education, procurement and supply chain experience, and technical skills
2. `ggales_eow1.ipynb`: a Python lab covering variables, arithmetic, string handling, list statistics, and an order total calculation with discount and tax

## How to Run Program
1. Download both files from this repository.
2. Open the résumé with any PDF reader.
3. Open `ggales_eow1.ipynb` in Jupyter Notebook or JupyterLab.
4. Select **Run All** to run the notebook from top to bottom.
